# 작업 기록 (worklog)

이슈 하나를 구현하고 나서 남기는 기록이다. `mvp-feature` 스킬의 마지막 단계에서 작성된다.

- 파일명: `YYYY-MM-DD-<이슈번호>-<슬러그>.md` (예: `2026-07-28-142-fare-policy-api.md`)
- 템플릿: `.claude/skills/mvp-feature/assets/worklog-template.md`
- 이슈당 한 파일. 같은 이슈로 다시 작업하면 새로 만들지 말고 기존 문서에 이어 쓴다.

## 여기에 쓰는 것 / 쓰지 않는 것

이 문서의 목적은 **코드에 남지 않는 판단을 남기는 것**이다.
클래스 목록이나 메서드 시그니처는 코드를 읽으면 알 수 있으니 쓰지 않는다. 대신:

- 구현 중 사람에게 물어서 고른 선택과 그 근거 (고르지 않은 대안이 왜 탈락했는지 포함)
- 물어볼 정도는 아니었지만 다르게 갈 수도 있었던 판단
- 이슈 범위에서 일부러 뺀 것과 그 이유
- 검증하지 못한 것 (예: H2에서 재현되지 않는 MySQL 동작)
- 새로 생긴 미결 사항 — 이건 `CLAUDE.md`의 「확인이 필요한 항목」에도 같이 추가한다

설계 근거를 길게 다루는 ADR은 여전히 GitHub Wiki가 정본이다.
여기 문서는 "이 이슈를 이렇게 처리했다"의 기록이지 ADR을 대체하지 않는다.
